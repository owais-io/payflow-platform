## Goal
Setting up git repos with readme files, .gitignore, licenses , defined rulesets to protect the main branch to merge only through pull requests.

## What I did
1. SSH and git identity

Generate an ed25519 SSH key, add it to GitHub, and test it with ssh -T git@github.com.
Set git config --global for user.name, user.email 
Run gh auth login so the GitHub CLI works too.

2. Create both repos

payflow-app: public, README, MIT licence, Python .gitignore.
payflow-platform: public, README, MIT licence, Terraform .gitignore.

3. Protect main

Use a ruleset under Settings → Rules → Rulesets: require a pull request before merging, and block force pushes and deletion.

4. Clone the repos

5. First commit, through a PR
